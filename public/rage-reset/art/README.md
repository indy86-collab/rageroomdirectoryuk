# Rage Reset art & audio

Procedural Canvas illustrators currently power the `next` renderer (see `lib/rage-reset/art/`).

Place exported bitmap/SVG enhancements here using the asset manifest keys:

- office/background/
- office/objects/ (intact / light / medium / heavy / destroyed)
- office/debris/
- office/boss/
- weapons/
- effects/
- ui/

Audio: original or licensed-for-commercial-use only. No copyrighted game audio.

Usage rights: all procedural artwork in this repo is original to Rage Reset.
